## 글씨 영역 다듬기

손글씨를 촬영하거나 사진에서 가져온 뒤 **선택 수정**을 누르면 실제로 보관할 글씨 영역을 조정할 수 있습니다.

- **포함** 도구로 남길 글씨를 칠합니다.
- **제외** 도구로 배경, 그림자나 다른 문장을 지웁니다.
- 브러시 크기를 바꾸어 좁은 획과 넓은 영역을 다룹니다.
- 되돌리기, 화면 맞춤과 초기화로 선택을 다시 조정합니다.

여러 장을 가져왔다면 위쪽의 페이지 표시를 이용해 장별로 확인합니다. 편집 결과를 바꾸어도 촬영 원본은 그대로 보존됩니다.

## 옮겨 둔 글씨 보기

홈 정원에서 손글씨 영역을 열거나 **모두 보기**를 누르면 **옮겨 둔 글씨** 갤러리가 나타납니다. 날짜별 카드에서 글씨 이미지를 고르면 해당 생각 상세 화면으로 이동합니다.

## 손글씨 이미지 공유하기

1. 손글씨 생각의 상세 화면에서 **공유**를 누릅니다.
2. 공유 비율을 선택합니다.
3. **갈피 로고 넣기**를 켜거나 끕니다.
4. 미리보기와 페이지 수를 확인합니다.
5. **공유하기**를 눌러 사진 앱, 메시지 또는 다른 앱으로 보냅니다.

| 비율 | 용도 |
| --- | --- |
| **자동** | 글씨 길이에 맞춰 자연스럽게 구성합니다. |
| **스토리** | 세로형 소셜 미디어 화면에 맞춥니다. |
| **피드** | 긴 글씨를 정사각형에 가까운 여러 장으로 나눕니다. |

## 손글씨체 바꾸기

**설정 > 손글씨체**에서 갈피에 포함된 글씨체를 미리 보고 선택할 수 있습니다. TTF·OTF 파일을 가져와 내 글씨체로 사용할 수도 있습니다.

선택한 손글씨체는 앱 제목·버튼·안내 같은 손글씨 영역에도 적용됩니다. 원문·입력값·날짜·개수는 읽기 편한 일반 글꼴로 표시됩니다.

가져온 글꼴 파일은 이 기기 안에만 저장됩니다. 다른 기기에서도 사용하려면 해당 기기에서 가져오세요. 글꼴을 사용하거나 공유할 때는 제공처의 라이선스를 확인하세요.
