---
title: "Sync and backup"
description: "Use personal iCloud sync and keep a separate ZIP backup of your records and originals."
---

## Turn on iCloud sync

1. Open **Settings** from Home.
2. Open **iCloud sync**.
3. Enable personal iCloud sync.
4. Once connected, check the last sync time and pending records and originals.

Use the sync-now action when you want to request an immediate sync. Turning sync off does not automatically delete records already stored on the device or in iCloud.

<Note>
iCloud sync helps you continue across devices using the same Apple account. A separate backup file also protects against mistakes or account problems.
</Note>

## Export a backup

1. Open **Settings > Backup and restore**.
2. Choose the export action. If an older backup is shown, create a new export.
3. Wait for Galpi to gather and verify the data and original files.
4. Share the backup to a safe location in Files or iCloud Drive.

The ZIP backup includes record data and original assets such as audio and handwriting images.

To search text from an exported ZIP with GPT or Claude on your Mac, see the [local MCP guide](/en/ask-with-ai). This is separate from iCloud sync and reads only the exported snapshot.

## Restore a backup

1. Choose a backup file in **Settings > Backup and restore**.
2. Select the ZIP file.
3. Check its date and record and asset counts.
4. Read the replacement notice, then start restoring.
5. When preparation is complete, fully quit Galpi and reopen it.

Restoring replaces the current data with the backup contents. Galpi creates a backup of the current data before staging the restore. A backup that fails validation does not change the existing data.

<Warning>
After restore preparation, saving new records is locked until you quit and reopen the app. Follow the completion instructions before adding more records.
</Warning>
