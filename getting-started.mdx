## 필요한 환경

- iOS 또는 iPadOS 26 이상이 설치된 iPhone·iPad
- iCloud 동기화를 사용할 경우 기기에 로그인된 Apple 계정과 사용할 수 있는 iCloud 연결
- 고급 손글씨 인식, YouTube 자막 가져오기, 상세 월간 회고와 온라인 자료 검색을 사용할 경우 인터넷 연결
- 음성 인식·번역 언어 모델을 처음 준비할 때는 추가 다운로드가 필요할 수 있습니다.

홈은 기록과 자료가 잎과 꽃으로 쌓이는 월별 정원입니다. 멈춰 둔 녹음이나 오늘 남길 생각을 여기서 이어갈 수 있습니다.

## 처음 확인할 권한

갈피는 기능을 처음 사용할 때 필요한 권한만 요청합니다.

- **마이크**: 음성 원본을 녹음할 때 사용합니다.
- **음성 인식**: 저장한 음성을 기기 안에서 검색 가능한 글로 바꿀 때 사용합니다.
- **카메라와 사진**: 종이 손글씨를 촬영하거나 사진 보관함에서 고를 때 사용합니다.
- **위치**: 현재 지역의 일출·일몰에 맞춰 홈의 해와 달을 표시할 때 사용합니다. 위치 자체는 저장하지 않습니다.
- **알림**: 정해 둔 루틴과 다시 볼 시간을 알려줄 때 사용합니다.

권한을 나중에 바꾸려면 iPhone 또는 iPad의 **설정 > 앱 > 갈피**에서 변경하세요.

## 첫 기록 남기기

1. **홈**에서 글, 음성 또는 손글씨 입력을 선택합니다.
2. 내용을 입력하거나 녹음·촬영합니다.
3. **기록 저장**을 누릅니다.
4. 아래의 **생각** 화면에서 방금 남긴 기록을 확인합니다.

<Tip>
기록 화면으로 빠르게 들어가고 싶다면 갈피의 앱 단축어나 제어 센터·잠금 화면 버튼을 추가해 보세요. 버튼은 갈피의 입력 화면을 열며, 녹음은 화면에서 **녹음 시작**을 눌러 시작합니다.
</Tip>
