## iCloud 동기화 켜기

1. 홈의 메뉴에서 **설정**을 엽니다.
2. **iCloud 동기화**를 선택합니다.
3. **개인 iCloud 동기화**를 켭니다.
4. 연결이 끝나면 마지막 동기화 시각과 대기 중인 기록·원본 수를 확인합니다.

필요하면 **지금 동기화**를 눌러 즉시 동기화를 요청할 수 있습니다. 동기화를 끄더라도 기기와 iCloud에 이미 저장된 기록은 자동으로 삭제되지 않습니다.

<Note>
iCloud 동기화는 같은 Apple 계정의 기기 사이에서 기록을 이어 쓰기 위한 기능입니다. 별도의 백업 파일도 정기적으로 보관하면 실수나 계정 문제에 더 잘 대비할 수 있습니다.
</Note>

## 백업 내보내기

1. **설정 > 백업·복원**을 엽니다.
2. **내보내기**를 선택합니다. 기존 백업이 표시되면 **새로 내보내기**로 새 파일을 만듭니다.
3. 갈피가 기록과 원본 파일을 모으고 검증할 때까지 기다립니다.
4. **백업 공유**를 눌러 파일 앱이나 iCloud Drive의 안전한 위치에 저장합니다.

백업에는 기록 데이터와 음성·손글씨 같은 원본 자산이 함께 포함됩니다.

내보낸 ZIP의 텍스트 기록을 Mac에서 GPT·Claude와 함께 찾아보고 싶다면 [로컬 MCP 연결 안내](/ask-with-ai)를 참고하세요. 이 연결은 앱의 iCloud 동기화와 별개이며 백업 시점의 내용만 읽습니다.

## 백업 복원하기

1. **설정 > 백업·복원**에서 **백업 파일 선택**을 누릅니다.
2. 복원할 ZIP 파일을 고릅니다.
3. 날짜, 레코드 수와 자산 수를 확인합니다.
4. 경고 내용을 읽고 **복원 시작**을 누릅니다.
5. 준비 완료 안내가 나타나면 갈피를 완전히 종료했다가 다시 엽니다.

복원은 현재 데이터를 백업 내용으로 전체 교체합니다. 갈피는 시작 전에 현재 데이터를 자동으로 백업하고, 파일 검증을 통과하지 못하면 기존 데이터를 변경하지 않습니다.

<Warning>
복원 준비가 끝난 뒤 앱을 다시 열기 전까지는 새 기록 저장이 잠깁니다. 안내된 순서대로 앱을 완전히 종료하고 다시 실행하세요.
</Warning>
