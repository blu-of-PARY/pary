음성 전사와 손글씨 인식은 원본을 저장한 뒤 진행됩니다. 결과는 검색과 다시 읽기를 돕는 글이며, 원본 음성·이미지를 바꾸지 않습니다.

## 기본 인식

- **음성 전사**는 Apple의 기기 내 음성 인식을 사용합니다. 처음에는 권한과 언어 모델 준비가 필요할 수 있습니다.
- **손글씨 기본 인식**은 Apple Vision으로 기기 안에서 처리하며 횟수 제한이 없습니다.
- 인식 오류는 생각 상세에서 수정할 수 있습니다. **처음 인식한 글**과 원본도 함께 확인할 수 있습니다.

## 손글씨 고급 인식

**설정 > 손글씨 인식**에서 **고급 인식**을 선택합니다. 손글씨 이미지가 Google의 Gemini로 전송된다는 안내에 동의하면 새로 저장하는 손글씨부터 적용됩니다.

앱 제공 사용량은 설정 화면에서 확인합니다. 제공량을 먼저 사용하고, 소진 뒤 연결된 개인 Gemini API 키로 이어갈 수 있습니다. **고급 인식에 개인 키 사용**을 켜면 개인 키를 우선 사용합니다. 개인 키를 통한 사용에는 해당 서비스의 사용량과 과금 정책이 적용됩니다.

개인 키는 **설정 > 고급 설정 > 개인 Gemini API 키**에서 연결·교체·삭제합니다. 키는 Keychain에 저장되고 iCloud Keychain 설정에 따라 다른 기기와 동기화될 수 있으며, 화면에는 다시 표시되지 않습니다.

## YouTube 자막 가져오기

1. YouTube 링크를 수집함에 저장합니다.
2. 자료 상세에서 **자막 가져오기**를 누릅니다.
3. 가져온 구간을 읽고 타임스탬프로 영상과 대조합니다.

현재 자막 가져오기는 공개된 자막 트랙을 가져오는 기능이며 개인 Gemini API 키가 필요하지 않습니다. 요청할 때 영상 식별자와 언어, 설치 식별자가 갈피의 중계 서버로 전송됩니다. 공개 자막이 없거나 영상에 접근 제한이 있으면 가져오지 못할 수 있습니다.

자동 생성 자막은 부정확할 수 있으므로 영상과 비교해 필요한 부분을 수정하세요. 자료 화면 안에서 영역을 접거나 언어를 바꾸어도 작업은 이어지며, 자료 상세 화면을 떠나면 진행 중인 가져오기는 중단됩니다.

## 자료를 한국어·영어로 읽기

자료 상세의 지구본 모양 **언어** 메뉴에서 **원문**, **한국어**, **English** 중 하나를 고릅니다. 한국어 또는 영어를 선택한 뒤 **본문 번역**이나 **전사 전체 번역**을 요청하면 Apple의 번역 기능을 사용합니다.

저장된 자막·전사가 있으면 그 본문을, 없으면 번역 가능한 제목·발췌를 대상으로 합니다. 언어 모델을 처음 준비할 때 다운로드가 필요할 수 있습니다. 원문이 이미 선택한 언어이거나 읽을 본문이 없으면 번역을 시작할 수 없습니다.

번역은 원문을 덮어쓰지 않고 별도로 보여 줍니다. 지원하는 원문 언어와 모델 준비 상태에 따라 이용 가능 여부가 달라집니다. 다른 자료로 이동하면 이전 자료의 번역을 새 자료의 내용으로 표시하지 않습니다.

## 월간 회고

기본 월간 회고는 기기 안의 기록으로 만들어집니다. **상세 회고**는 요청하고 외부 분석에 동의할 때만 만들어집니다. 선택한 달의 기록에서 제목·날짜·종류·텍스트 일부가 갈피의 중계 서버를 거쳐 OpenAI로 전송됩니다. 원본 사진이나 녹음 파일 자체를 월간 회고 입력으로 보내지는 않습니다.

동의와 저장된 상세 회고는 **설정 > 개인정보**에서 관리합니다. 동의 철회와 저장된 상세 회고 삭제는 별도 동작입니다.
