## 화면 모드 바꾸기

**설정 > 화면 모드**에서 시스템 설정 따르기, 밝은 화면 또는 어두운 화면을 선택합니다.

## 기록 언어 바꾸기

**설정 > 기록 언어**에서 한국어, English, 기기 언어 중 하나를 고릅니다. 음성 전사와 손글씨 인식에 적용되는 언어이며 앱 화면 언어와는 별개입니다. [기록 언어 안내](/capture-thoughts)를 참고하세요.

## 위젯 추가하기

1. 홈 화면의 빈 곳을 길게 누릅니다.
2. **편집 > 위젯 추가**를 누릅니다.
3. **갈피**를 검색합니다.
4. 원하는 크기의 위젯을 골라 추가합니다.

작은 위젯은 누르면 음성 기록 화면을 엽니다. 중간 크기 위젯에서는 **열어보기**로 최근 자료를 열고, **말하기** 또는 **쓰기**로 음성·텍스트 기록 화면을 선택할 수 있습니다.

위젯은 앱의 입력 화면을 엽니다. 음성은 화면에서 **녹음 시작**을 눌러야 녹음됩니다.

## 제어 센터에 기록 버튼 추가하기

1. 제어 센터를 엽니다.
2. 빈 곳을 길게 누르거나 추가 버튼을 누릅니다.
3. **제어 항목 추가**에서 갈피를 검색합니다.
4. 음성, 글 또는 손글씨 기록 버튼을 배치합니다.

제어 센터나 잠금 화면에서 버튼을 누르면 갈피의 해당 기록 화면이 바로 열립니다.

## 앱 단축어 사용하기

단축어 앱에서 갈피가 제공하는 기록 동작을 찾아 자동화나 홈 화면 아이콘에 연결할 수 있습니다. 음성·글·손글씨 중 자주 쓰는 동작을 선택하세요.

<Tip>
가장 자주 쓰는 기록 방식 하나만 잠금 화면이나 제어 센터에 두면 선택 단계를 줄일 수 있습니다.
</Tip>

## 개인정보와 AI 연결 확인하기

- **설정 > 개인정보**: 외부 분석 동의와 저장된 상세 회고를 관리합니다.
- **설정 > 고급 설정**: 개인 Gemini API 키를 연결하거나 확인합니다.
- **설정 > 앱 정보**: 앱 버전과 오픈소스·폰트 고지를 확인합니다.

AI 기능별 전송 범위는 [AI 기능 사용하기](/ai-features)를 참고하세요.
