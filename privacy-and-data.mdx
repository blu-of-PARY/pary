이 페이지는 갈피의 기능별 데이터 사용을 설명합니다. 어떤 기능을 켜고 무엇을 공유할지 결정할 때 참고하세요.

## 원본과 텍스트

저장한 음성과 손글씨 이미지는 원본으로 보관합니다. 인식된 텍스트와 사용자가 수정한 본문은 원본과 구분됩니다. 텍스트를 수정해도 원본 음성이나 사진이 그 내용으로 덮어써지지 않습니다.

기록 저장이 끝난 뒤 인식을 진행하므로, 인식에 실패해도 저장된 원본을 열어볼 수 있습니다. 저장하기 전에 취소한 녹음은 이 보관 대상에 포함되지 않습니다.

## 기능별 처리 위치

| 기능 | 처리와 전송 |
| --- | --- |
| 타이핑·원본 보관 | 기기에 저장합니다. |
| 음성 전사 | Apple의 기기 내 음성 인식을 사용합니다. 언어 모델 다운로드가 필요할 수 있습니다. |
| 손글씨 기본 인식 | Apple Vision으로 기기 안에서 처리합니다. |
| 손글씨 고급 인식 | 이미지와 인식 언어를 Gemini로 보냅니다. 앱 제공 경로는 갈피 중계 서버를 사용하고, 사용량 관리를 위한 설치 식별자도 보냅니다. 개인 키 경로는 Google에 직접 요청합니다. |
| YouTube 자막 가져오기 | 요청할 때 영상 식별자·언어·설치 식별자를 갈피 중계 서버로 보내 공개 자막을 가져옵니다. 개인 API 키는 필요하지 않습니다. |
| 자료 번역 | Apple 번역 기능을 사용하며 필요한 언어 모델을 준비합니다. |
| 기본 월간 회고 | 기기 안의 기록으로 만듭니다. |
| 상세 월간 회고 | 동의 후 요청할 때 기록의 제목·날짜·종류·텍스트 일부를 중계 서버를 거쳐 OpenAI로 보냅니다. 원본 음성·사진 파일 자체는 보내지 않습니다. |
| 개인 iCloud 동기화 | 켜면 기록과 원본을 Apple 계정의 개인 iCloud 영역에 동기화합니다. |

링크 미리보기·웹 본문 가져오기·책과 논문 검색은 해당 웹사이트나 검색 서비스에 온라인으로 요청합니다. 원문 열기와 다른 앱으로 공유하기에도 해당 서비스의 데이터 처리가 적용됩니다.

## 권한과 동의 관리

- 마이크·음성 인식·카메라·사진 권한은 기기의 **설정 > 앱 > 갈피**에서 관리합니다.
- 손글씨 고급 인식은 **갈피 설정 > 손글씨 인식**에서 기본 인식으로 바꿀 수 있습니다.
- 상세 회고 동의는 **설정 > 개인정보**에서 철회할 수 있습니다.
- 개인 Gemini API 키는 **설정 > 고급 설정**에서 삭제할 수 있습니다. 키는 Keychain에 저장되고 iCloud Keychain 설정에 따라 다른 기기와 동기화될 수 있습니다.
- 정원의 일출·일몰 계산에 쓰는 위치는 저장하지 않습니다. 위치 권한 없이도 기록할 수 있습니다.

## 삭제와 복원

생각이나 자료를 휴지통으로 옮기면 30일 안에 복원할 수 있습니다. 영구 삭제는 원본과 관련 데이터를 삭제하므로 되돌릴 수 없습니다. 자세한 동작은 [보관함과 휴지통](/manage-library)을 확인하세요.

상세 회고의 동의 철회와 이미 저장된 상세 회고 삭제는 별도입니다. **설정 > 개인정보 > 저장된 상세 회고 삭제**에서 삭제할 수 있습니다. 기기의 저장된 결과를 지우는 동작은 외부 서비스에 이미 처리 요청한 내용을 되돌리는 동작이 아닙니다.

동기화를 끄는 것만으로 기존 기기·iCloud 기록이 삭제되지는 않습니다. 내보낸 ZIP 백업과 다른 앱에 공유한 사본은 사용자가 해당 위치에서 별도로 관리합니다.

<Tip>
외부 AI 기능을 사용하지 않아도 글·음성·손글씨 기록과 기본 인식을 이용할 수 있습니다. 동기화와 온라인 자료 기능까지 포함해 앱 전체가 오프라인으로만 동작하는 것은 아닙니다.
</Tip>

## 외부 서비스의 데이터 안내

세부 보관 조건과 무료·유료 API의 데이터 이용 조건은 [OpenAI 데이터 사용 안내](https://platform.openai.com/docs/guides/your-data)와 [Gemini API 이용약관](https://ai.google.dev/gemini-api/terms)을 확인하세요. 서비스와 계정의 조건에 따라 다를 수 있습니다.
