---
title: "문제 해결"
description: "공유, 권한, 인식, 동기화가 기대대로 동작하지 않을 때 확인합니다."
---

## 공유 목록에 갈피가 없어요

1. Safari나 YouTube에서 **공유**를 누릅니다.
2. 앱 목록 끝의 **더 보기**를 엽니다.
3. **편집**에서 갈피를 켜고 즐겨찾기에 추가합니다.
4. 그래도 보이지 않으면 기기를 한 번 재시작한 뒤 다시 확인합니다.

## 음성이나 손글씨를 사용할 수 없어요

iPhone 또는 iPad의 **설정 > 앱 > 갈피**에서 마이크, 음성 인식, 카메라, 사진 권한을 확인하세요. 권한을 바꾼 뒤 갈피로 돌아와 입력을 다시 시작합니다.

## 손글씨 인식 결과가 달라요

- 상세 화면에서 촬영 원본과 인식 결과를 함께 비교합니다.
- 글씨 영역 선택에서 배경이나 다른 문장을 제외합니다.
- 기본 인식의 **비슷한 단어로 자동 교정**을 끄거나 켜 결과를 비교합니다.
- 필요하면 고급 인식을 사용하되, 외부 전송 안내를 먼저 확인합니다.

## 녹음은 있는데 전사문이 없어요

- 생각 상세 화면의 원본 재생으로 녹음이 저장되어 있는지 확인합니다.
- 음성 인식 권한과 인식 언어를 확인합니다.
- 처음 사용하는 인식 언어는 모델 준비를 위해 인터넷 연결과 여유 저장 공간이 필요할 수 있습니다.
- 처리 중이면 잠시 기다리고, 실패나 다시 시도 안내가 나오면 기록 상세에서 재시도합니다.
- 사용하는 기기에서 인식을 지원하지 않아도 저장된 원본을 들으며 본문을 직접 적을 수 있습니다.

## YouTube 자막이나 번역을 가져오지 못해요

- 인터넷 연결을 확인합니다.
- YouTube 자막 가져오기는 개인 Gemini API 키와 관계없이 작동합니다. 공개 자막이 없는 영상은 가져올 수 없습니다.
- 비공개·연령 제한 등으로 영상에 접근할 수 없거나 중계 서버가 응답하지 않으면 가져오지 못할 수 있습니다.
- 한국어·영어 번역을 시작할 때 필요한 언어 모델과 저장 공간을 확인합니다.
- 화면에 오류별 다시 시도 안내가 있다면 잠시 뒤 다시 실행합니다.

## iCloud 동기화가 멈춘 것 같아요

1. 기기의 Apple 계정과 iCloud Drive 상태를 확인합니다.
2. 갈피의 **설정 > iCloud 동기화**에서 상태 메시지와 대기 중 수를 확인합니다.
3. **지금 동기화**를 누릅니다.
4. 문제가 계속되면 먼저 ZIP 백업을 만든 뒤 앱 버전과 표시된 상태 메시지를 함께 기록해 문의하세요.

## 복원 뒤 화면이 바뀌지 않아요

복원 준비 완료 안내 뒤에는 앱 전환만 하지 말고 갈피를 완전히 종료한 다음 다시 열어야 합니다. 검증에 실패했다면 다른 백업 파일을 선택하세요. 실패한 복원은 현재 데이터를 바꾸지 않습니다.

## 루틴 알림이 오지 않아요

- **설정 > 루틴**에서 알림 받기와 선택한 요일을 확인합니다.
- 기기 **설정 > 알림 > 갈피**에서 알림을 허용합니다.
- 시간을 바꾼 뒤 설정 화면을 나가 새 예약이 반영되었는지 확인합니다.
- 알림이 꺼져 있어도 홈의 오늘의 갈피에서 직접 기록할 수 있습니다.

## 위젯이나 제어 항목에 갈피가 없어요

갈피를 한 번 실행한 뒤 위젯 또는 제어 센터 추가 화면을 다시 여세요. 그래도 보이지 않으면 기기를 재시작하고 최신 갈피 빌드가 설치되어 있는지 확인합니다.

## 공유한 대화 본문이 비어 있어요

공유 페이지의 접근 권한이나 서비스 구조 때문에 본문을 읽지 못했을 수 있습니다. 대화 전체를 복사한 뒤 갈피의 대화 상세 화면에서 **붙여넣은 원문 저장**을 사용하세요.

## 문제 상황 남기기

해결되지 않으면 기기 모델, OS 버전, **설정 > 앱 정보**의 갈피 버전, 오류 문구와 발생 순서를 적어 두세요. 화면을 공유할 때는 개인 기록이나 API 키가 보이지 않도록 확인합니다.

기록이 사라진 것처럼 보여도 먼저 휴지통과 동기화 상태를 확인하고, 현재 데이터를 [백업](/sync-and-backup)해 두세요. 백업 확인 전 앱을 삭제하면 기기에만 있던 원본을 잃을 수 있습니다.
